Hackathon II — All phases completed and live now!

I just wrapped up a full-stack Todo application built end-to-end across five iterative phases. TaskFlow Pro is a multi-user task management app with an AI-powered chatbot that can create, update, and manage your tasks through natural conversation.

On the tech side, the frontend runs on Next.js 16+ with the App Router, React 19, TypeScript, and Tailwind CSS 4. The backend is powered by FastAPI with SQLAlchemy ORM, JWT authentication, and bcrypt password hashing. The AI chatbot connects to OpenRouter (Mistral 7B) with full tool-calling support for hands-free task management.

For DevOps and quality, the entire stack runs locally via Docker Compose with multi-stage builds. GitHub Actions CI/CD runs pytest (8 backend tests) and Jest (7 frontend tests) on every push. Structured logging gives clean, parseable output across all backend services.

The app is deployed with the frontend on Vercel and the backend on Hugging Face Spaces with a Neon PostgreSQL database. Every phase — from the initial UI to Docker to this final quality pass — is documented with specs, plans, and architecture decision records.
